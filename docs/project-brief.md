He implementado una animación básica de entrada para las project cards utilizando CSS y una pequeña parte de JavaScript. Utilicé la API Intersection Observer para activar las animaciones cuando las tarjetas entran en el viewport. CSS define el estado inicial y final de la transición, mientras que JavaScript se encarga de añadir la clase animate-in en el momento adecuado.
